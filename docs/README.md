# Documentation Index

| Path                  | Contents                                                      |
|-----------------------|---------------------------------------------------------------|
| `architecture/`       | System design docs, firmware architecture, issue post-mortems |
| `guides/`             | Bring-up, validation and integration guides                   |
| `hardware/`           | Client reports; raw CAD/BOM data lives in `/hardware`         |
| `api/`                | Module/API reference (see README inside)                      |
| `plans/`              | Historical implementation plans                               |
| `specs/`              | Design specs (includes the deprioritized model work)          |

Hardware design files (schematics, PCB, BOM, gerbers, STEP) are organized by
version under [`/hardware`](../hardware).
